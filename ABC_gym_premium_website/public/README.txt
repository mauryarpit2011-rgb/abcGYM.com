ABC.gym — premium animated gym website
Bhopal, Madhya Pradesh, India

Run locally:
1. Install Node.js
2. Open this folder in VS Code
3. Open Terminal
4. Run: npm install
5. Run: npm run dev
6. Open the local URL shown by Vite

Edit content:
- Main content: src/App.jsx
- Design/animations: src/styles.css
- Project settings: package.json

The demo uses remote Unsplash photography. Replace those image URLs with the gym's real photographs before a client launch.
The contact form is visual only until connected to a form/email backend.
